1 - Approche Logique 


1.1. Schéma Relationnel
A partir du modèle conceptuel de données proposé par le client, nous avons élaboré le modèle logique de données ci-dessous:


CLIENTS(CodeC, NomC, PrénomC, TelC, MelC)
AEROPORTS_DEP(CodeA, NomA)
CIRCUITS(CodeCI, NomCI, PrixBase,NbPersMax, #CodeCI_Est_Complete)
PAYS(CodeP, NomP, AvisGen)
SITES(CodeS, NomS, TypeS, DescripS)
ANIMATIONS(CodeAN, NomAN, TypeAN, HeureDeb, JourSemaine, #CodeH)
HOTELS(CodeH, NomH, Categorie, VilleH, TelH, MelH)
GUIDES(CodeG, NomG, PrenomG, DatePremier)
ZONE_GEO(CodeZ, ZoneGeo)
ACTIVITE(CodeAC, NomAC, TarifAC)
LANGUE(CodeL, NomL)
MOIS(CodeMois, LibelleMois)
CHOIX ( #CodeC, #CodeA, #CodeCI, DateDepartC, OrdrePreference )
RESERVER (  #CodeC, #CodeA, #CodeCI, DateDepartR, DateResa, NbPers )
MAJORATION ( #CodeA, #CodeCI,  DateDepartM, MontantMaj)
PRATIQUER ( #CodeG, #CodeL, NiveauL )
VALIDITE ( #CodeAC, DateDebut, DateFin ) 
REALISER ( #CodeCI, #CodeAC, DateDepartRe, JourSem )
LOGER ( #CodeCI, #CodeH, JourSe ) 
VISITER ( #CodeCI, #CodeS, JourSe2, HeureVisite, DureeVisite )
AVIS ( #CodeP, #CodeMois, TempMin, TempMax, AvisMens, TempMinMoy, TempMaxMoy )
SITUER ( #CodeCI, #CodeZ, #CodeP ) 
ACCOMPAGNER ( #CodeG, #CodeCI, DateDepartA)


1.2. Commentaires
Lors de l’élaboration du modèle relationnel, on s’est aperçu de quelques modifications indispensables pour garantir le bon fonctionnement de la base de données:


* Un changement des noms des attributs “Date” données sur le dictionnaire de données était nécessaire. “Date” étant une fonction sur notre future base de données Oracle. Donc pour la relation Reserver par exemple, au lieu de mettre “Date” comme nom, nous avons plutôt défini “DateDepartR”. Les noms d’attributs choisis sont : DateDepartC, DateDepartM, DateDepartA, DateDepartRe.
* Tous les noms des relations ont été défini en majuscules.
* Tous les attributs ou tables ayant des accents ont été écrits sans accents.

2.1.1. Requête 1


Donner le montant total du circuit "Les saveurs tunisiennes", partant de l'aéroport de Toulouse le 08/07/2026, réservé par Monsieur Medhi TERRANER.


SELECT cl.nomC, cl.prenomC, r.dateDepartR, c.nomCI, ad.nomA, c.prixBase + m.montantMaj AS montant_total_du_circuit
FROM Circuits c, Majoration m, Aeroports_Dep ad, Reserver r, Clients cl
WHERE c.codeCI = m.codeCI
AND m.codeA = ad.codeA
AND ad.codeA = r.codeA
AND r.codeC = cl.codeC
AND r.codeCI = c.codeCI
AND r.dateDepartR = m.dateDepartM
AND LOWER(c.nomCI) = 'les saveurs tunisiennes'
AND LOWER (ad.nomA) = 'toulouse'
AND r.dateDepartR = TO_DATE('08/07/2026', 'DD/MM/YYYY')
AND LOWER (cl.prenomC) = 'medhi'

2.1.8. Requête 8


Donner les coordonnées du client ayant effectué le plus de circuits pour chaque pays.


SELECT p.nomP, COUNT(DISTINCT r.codeci) AS nbCircuits, c.nomc, c.prenomc, c.telc, c.melc
FROM clients c, reserver r, circuits ci, situer s, pays p
WHERE c.codec = r.codec
AND r.codeci = ci.codeci
AND ci.codeci = s.codeci
AND s.codep = p.codep
AND r.dateDepartR <= SYSDATE
GROUP BY c.codec, c.nomc, c.prenomc, c.telc, c.melc, p.codep, p.nomP
HAVING COUNT(DISTINCT r.codeci)  =
    (
        SELECT MAX(COUNT(DISTINCT r2.codeci))
        FROM reserver r2, circuits ci2, situer s2, pays p2
        WHERE r2.codeci = ci2.codeci
        AND ci2.codeci = s2.codeci
        AND s2.codep = p2.codep
        AND p.codep = p2.codep
        AND r2.dateDepartR <= SYSDATE
        GROUP BY r2.codeC
     )
ORDER BY p.nomP ASC;

2.1.9. Requête 9


Donner les noms des circuits disponibles au départ de Toulouse qui permettent de visiter tous les sites de Tunisie.


SELECT DISTINCT c.NomCI
FROM circuits c, majoration m, aeroports_dep a, situer s, pays p
WHERE c.CodeCI = m.CodeCI
AND m.CodeA = a.CodeA
AND c.CodeCI = s.CodeCI
AND s.CodeP = p.CodeP
AND LOWER(a.NomA) = 'toulouse'
AND LOWER(p.NomP) = 'tunisie'
AND m.datedepartm NOT IN (
   SELECT r.dateDepartR
   FROM reserver r
   WHERE r.CodeCI = c.CodeCI
   AND r.CodeA = m.CodeA
   GROUP BY r.dateDepartR
   HAVING SUM(r.NbPers) >= c.NbPersMax
)
AND NOT EXISTS (
   SELECT 1
   FROM situer s2, visiter v
   WHERE s2.CodeCI = v.CodeCI
   AND s2.CodeP = p.CodeP
   AND NOT EXISTS (
       SELECT 1
       FROM visiter v2
       WHERE v2.CodeCI = c.CodeCI
       AND v2.CodeS = v.CodeS
   )
);

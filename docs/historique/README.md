# Sources historiques du Groupe 1

Ces fichiers sont des archives pédagogiques retrouvées lors de la reconstruction. Les scripts SQL opérationnels et les livrables validés restent aux emplacements habituels du dépôt.

Les textes Google Docs sont exportés en UTF-8, sans réécriture de leur contenu ; ils ne conservent pas les images, la mise en page ni la présentation visuelle des clés. Le PDF du premier livrable conserve le MCD et sa mise en page. Les dates de révision ci-dessous sont données en UTC, telles que renvoyées par Drive ; les journées du journal sont celles du planning de travail en France.

Les copies évolutives (`creation-tables.sql`, `extractions-synthese.txt` et `rapport-travail.txt`) permettent de lire les changements dans les diffs des commits. Leur dernière version ne remplace pas les scripts ou PDF finaux.

Les noms des personnes sont ceux du groupe déjà crédité dans le dépôt. Les métadonnées de dernier éditeur d'un document ne permettent pas d'attribuer tout son contenu à cette personne ; elles ne sont pas utilisées comme une preuve d'auteur unique.
